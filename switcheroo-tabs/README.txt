Switcheroo Tabs
Install once: chrome://extensions, turn on Developer mode, Load unpacked, pick this folder.
Works with Switcheroo 8.6 or later. Keep HQ and your video as tabs in the same Chrome window.
1.1 (with Switcheroo 9.9.4): set a site to mute from its Tampermonkey menu and this extension mutes that whole tab while you talk to Claude.
After updating these files, click the reload arrow on Switcheroo Tabs in chrome://extensions.
